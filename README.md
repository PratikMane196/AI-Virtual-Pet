# AI-Powered Virtual Pet

## About
A simple interactive virtual pet application developed using HTML, CSS, and JavaScript.

## Features
- Feed and play with the virtual pet.
- Chat with the pet.
- Display different moods and emotions.
- Simple and user-friendly interface.

## Technologies
HTML, CSS, JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Note
The current version uses predefined JavaScript responses and does not connect to a live Generative AI API.
